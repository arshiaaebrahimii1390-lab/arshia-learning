👈 بخش ۳ — This و That

برای اشاره به چیزی که نزدیک ماست، از This استفاده می‌کنیم.

This
دیس
این 👈

برای اشاره به چیزی که دورتر است، از That استفاده می‌کنیم.

That
ذَت
آن 👉

🧠 بخش ۴ — a و an

وقتی درباره‌ی یک چیز صحبت می‌کنیم، قبل از اسم معمولاً از a یا an استفاده می‌کنیم.

اگر کلمه با صدای بی‌صدا شروع شود، معمولاً از a استفاده می‌کنیم:

a book 📖
ا بوک

a pen 🖊️
ا پِن

a chair 🪑
ا چِر
اگر کلمه با صدای صدادار شروع شود، معمولاً از an استفاده می‌کنیم:

an apple 🍎
اَن اَپِل

an orange 🍊
اَن اُرِنج

⭐ نکته مهم: برای a / an بیشتر به صدا توجه می‌کنیم، نه فقط به حرف اول کلمه.

💬 بخش ۵ — جمله‌سازی

This is a book.
دیس ایز ا بوک
این یک کتاب است.
This is a pen.
دیس ایز ا پِن
این یک خودکار است.
That is a chair.
ذَت ایز ا چِر
آن یک صندلی است.
This is my phone.
دیس ایز مای فون
این گوشی من است.
This is my bag.
دیس ایز مای بَگ
این کیف من است.
That is a window.
ذَت ایز ا ویندو
آن یک پنجره است.
